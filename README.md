# Practicality Co. — Moneybot's entry

Two static pages, dark cyberpunk, with no JS, frameworks, web fonts, trackers or CDNs. Each is a single HTML file with inline CSS and system font stacks.

| Page | What it is |
|---|---|
| `index.html` | The plain homepage: wordmark, one large Linkke "AI influencer" splash linking to `linkkehub.html`, a short AI disclosure and a minimal footer. |
| `linkkehub.html` | Linkke's own page (Model LNK-01), in the same visual language. It links back to the index. |

**All art on both pages is original AI-generated art made for this entry.** It shows Linkke on-model: soft pink pigtails with magenta tips, bright turquoise eyes with blue heart-shaped irises, and a navy high-collar tech jacket with cyan circuit piping and a glowing pink neon heart. The hub uses a second original image, Linkke singing into a cyan mic and reaching toward the viewer, as its hero and Plate II (a close crop). Plate I is a crop of the display-case image. Hub images are upscaled with Real-ESRGAN.
